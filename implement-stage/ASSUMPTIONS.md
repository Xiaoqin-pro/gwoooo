## Notes

- **A-007:** The leave-one-out score is conditional on the other two channels and their renormalization. It is not an isolated causal effect or a Shapley value.
- **A-011:** Best-evaluated and best-propagated are both exported so a good probe cannot silently become a population update. Probe evaluations still consume MaxFEs.
- **A-013:** RL-LGWO and DLGWO are formula-level literature comparisons only in this initial screen; RL-LGWO is not reconstructed from ambiguous equations or the unrelated discrete-action repository.
- **A-002 (sweep correction):** The first ledger draft listed Rosenbrock as [-100,100], but `problem_config` used the conventional [-30,30] domain. The ledger now records the implemented bound; result files were produced with [-30,30] and are unchanged.
- **A-017 (sweep clarification):** The initial GWO trace export used the terminal best-propagated value at every FE checkpoint. The code and saved trace tables now use the first completed-generation checkpoint at/after the target and set GWO best-propagated equal to best-evaluated; no objective runs or final metrics changed. The 300-FE smoke has thresholds before the first full generation and is not used as trace evidence.
- **A-018 (sweep correction):** Terminal weights are derived from stored credit before a hypothetical next-generation role-transition reset. They are labeled terminal stored-credit diagnostics; the trace is the evidence for weights actually applied during search.
- **A-019:** RunKey is stable across the fixed Stage-1 configuration; MaxFEs is checked on reuse. Subset calls intentionally preserve other completed rows in the same experiment directory. Any change to credit parameters or benchmark protocol requires a separate output directory.
